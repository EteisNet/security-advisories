# Security Advisories

Este repositorio lista las vulnerabilidades que Eteisnet descubre y reporta de forma responsable a terceros.

Las entradas se publican **solo después de una divulgación coordinada**: cuando el mantenedor del proyecto afectado ya publicó el release parcheado y su advisory público.
